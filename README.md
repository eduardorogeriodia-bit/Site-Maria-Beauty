# Studio Maria Beauty

Site estático compatível com GitHub Pages. Publique a branch `main` usando a pasta raiz (`/`).

## Painel administrativo demonstrativo

- Acesso inicial: usuário `admin`, senha `teste123`.
- A senha pode ser trocada no painel; a alteração fica apenas no armazenamento local do navegador.
- Preços e vendas lançadas manualmente também ficam no `localStorage` desse navegador e não são compartilhados com outros dispositivos.

Este painel existe para demonstração escolar. Como o GitHub Pages entrega o código ao público e não oferece backend, essa autenticação não é segurança real e não deve guardar dados privados ou financeiros. Para administração real, use um backend e um banco de dados protegidos.
